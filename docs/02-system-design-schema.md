# 02 — System Design Schema

> Every system design generated by the platform MUST follow this standardized 26-section schema.
> This schema is the **data contract** between the AI engine, the backend, and the frontend.

---

## Why a Schema?

Without a schema, the LLM generates random, inconsistent, uncontrollable output. The schema:

1. **Guarantees completeness** — every design covers all 26 areas
2. **Enables structured storage** — each section maps to a database column/field
3. **Enables UI rendering** — each section maps to a UI panel/tab
4. **Enables comparison** — two designs can be diff'd section by section
5. **Enables validation** — each section can be validated against rules
6. **Enables progressive disclosure** — levels control which sections are shown

---

## The 26-Section Schema

### Section 1: Problem Definition

```json
{
  "section": "problem_definition",
  "content": {
    "title": "Design a Video Streaming Platform",
    "description": "A platform similar to YouTube where users can upload, transcode, store, and stream video content to millions of concurrent viewers.",
    "domain": "media_streaming",
    "similar_systems": ["YouTube", "Netflix", "Vimeo", "Twitch"]
  }
}
```

**AI Prompt Guidance**: Extract the core problem. Identify the domain. List similar real-world systems.

### Section 10: Data Flow

```json
{
  "section": "data_flow",
  "content": {
    "flows": [
      {
        "name": "Video Upload Flow",
        "steps": [
          "User uploads video via API",
          "API Gateway routes to Video Service",
          "Video Service stores raw video in S3",
          "Video Service publishes TRANSCODE event to Kafka",
          "Transcoding Worker consumes event",
          "Worker transcodes video to multiple resolutions",
          "Worker stores transcoded versions in S3",
          "Worker publishes TRANSCODE_COMPLETE event",
          "Video Service updates video status to 'ready' in PostgreSQL"
        ]

      {
        "name": "Video Streaming Flow",
        "steps": [
          "User requests video",
          "Request hits CDN",

      }
    ]
  }
}
```
